# 装备台账 · 山野手账

一个纯本地的户外装备管理小工具。记录买入价和每次出行，自动算出**日均成本**和**单次使用成本**，
把"这件东西到底值不值"变成看得见的数字。

## 两种模式

| 模式 | 怎么开 | 数据在哪 |
|---|---|---|
| **云同步**（默认开启） | ⚙ → 连接云同步 → 粘 GitHub Token | 你自己的私有 GitHub Gist |
| **纯本地** | `config.js` 里 `syncProvider` 改成 `''` | 只在当前浏览器 |

云同步免费、不过期，手机和电脑自动同步。配置步骤见本机的 `文档/部署指南.md`，5 分钟搞定。

> 没连 Token 也能正常用，只是数据只在本机。连上之后会自动把本地数据合并上去。

## 怎么打开

**方式一（推荐）**：双击本机的 `工具\启动.bat`
- 会自动打开浏览器，地址是 http://127.0.0.1:8765/
- 同一个 Wi-Fi 下的手机，用命令行里打印的局域网地址也能打开
- 关掉黑窗口就停止服务，数据不会丢

**方式二**：直接双击 `index.html`
- 能打开，但部分浏览器对本地文件的存储限制较严，建议用方式一

## 数据存在哪

全部存在浏览器的 localStorage 里，**不上传、不联网、不需要账号**。

⚠️ 三个注意事项：
1. 清除浏览器数据 / 换浏览器 / 换电脑，数据会没
2. 换设备前先在 ⚙ 里**导出 CSV**
3. CSV 同时也是你的备份文件，建议一个月导一次

## 五个页面

| 页面 | 干什么 |
|---|---|
| **资产** | 台账主界面。按状态（服役中/已超期/已退役/预备役）和分类筛选，一眼看到每件东西的持有天数和日均；详情页有使用履历和补录入口 |
| **装备库** | 装备资料卡：参数、性能评级、参考价。点「加入我的资产」会带着参数一起进台账 |
| **行程** | 行程列表、装备清单、实际使用确认、费用核算；同页还有全量使用记录和打包模板 |
| **分析** | 总投入、分类占比、单次成本排行、闲置率、行程花费排行、超期提醒 |
| **我的** | 货币、深色模式、分类管理、导入导出、分享图 |

## 行程怎么用

1. **新建行程**：填名称、日期、类型、人数和交通/住宿/其他花费。选择行程类型后，会提示套用对应的打包模板。
2. **套用模板**：系统预置了轻装一日、重装露营、多日穿越、雪山攀登、城市周边五套模板；也可以从自己的资产里建自定义模板。
3. **确认实际使用**：行程开始后点「完成行程」，逐项勾选实际携带/实际使用；勾了「使用」的装备会自动生成使用记录，并计入单次成本。
4. **看成本**：行程详情里能看到装备成本、交通、住宿、其他、总成本和人均；除数为 0 或数据缺失时显示「数据不足」。
5. **删除行程**：如果已经生成过使用记录，可以选择「回滚使用记录」或「保留记录（转为手动补录）」，不会留下孤立数据。

**使用记录**是成本统计的唯一数据源。完成行程会自动生成；以前用过的装备也可以在资产详情页点「补录」，
按日期和次数补上。撤销记录后，资产累计次数会同步回滚。

## 计算口径

```
总价   = 价格 × 数量 + 附加费用
日均   = (总价 − 二手价值) ÷ 持有天数
次均   = (总价 − 二手价值) ÷ 使用次数
退役日 = 购买日 + 计划使用年限
```

- **持有天数**：从购买日算到今天，购买当天算 0 天；为 0 时日均显示「数据不足」
- **减去二手价值**：开启后，日均和次均都按净成本算（适合还打算出掉的装备）
- **使用次数**：来自使用记录（行程自动生成 + 手动补录），不再在资产表单里直接改
- **已超期**：超过计划使用年限的物品会自动进入「已超期」标签

## 两个模块怎么联动的

装备库里点「加入我的资产」→ 打开录入表单，名称/参考价/图标自动带进来，同时记住来源；
保存后：
- 资产详情页底部多出「装备参数」区块（面料、防水指数、性能评级）
- 装备库对应的卡片变成「已在资产中」，并显示你的真实单次成本

这样"资料"和"我的成本"是同一份数据，不用两头填。
